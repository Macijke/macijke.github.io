FINANCE-FLOW SYSTEM

Fullstack Application • Java Spring Boot • React.js

Kompleksowa platforma do zarządzania finansami osobistymi. Projekt składa się z wydajnego REST API oraz nowoczesnego interfejsu użytkownika SPA.

// 1. Backend Service (Java 17)
  • Core: Spring Boot 3.1, Hibernate, PostgreSQL.
  • Security: Autentykacja JWT, Role-Based Access Control (RBAC).
  • Logic: Zarządzanie transakcjami, budżetowanie, algorytmy analizy.
// 2. Frontend Client (React)
  • UI/UX: Responsywny interfejs użytkownika z wizualizacją danych.
  • Integracja: Konsumpcja API przez Axios, obsługa tokenów JWT.
  • Features: Dashboard z wykresami, edycja budżetów w czasie rzeczywistym.
